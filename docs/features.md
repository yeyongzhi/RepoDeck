# 功能清单

| 模块 | 已实现功能 |
| --- | --- |
| 仓库管理 | 本地添加、代码目录扫描、分组、置顶、搜索、组合状态筛选、失效路径重新定位 |
| 克隆 | HTTPS / SSH、快速克隆、登记与分组、历史目录、估算总体进度、后台任务、停止保留或删除 |
| Git | Fetch、快进拉取、提交、推送、分支管理、提交历史、工作区审阅、对比、Stash 与标签工具 |
| 任务中心 | 克隆和 Git 操作记录、失败说明及日志、异常退出的中断状态 |
| 数据 | SQLite 业务存储、迁移旧配置、JSON 交换包、导入预览、备份与事务回滚 |
| 偏好 | 编辑器与终端、启动页、布局、主题、字号、圆角、侧栏与窗口状态 |

RepoDeck 调用本机 Git，不代管远端账号或 SSH 密钥。本次仅提供 Windows x64 测试版，不包含自动下载仓库代码的数据恢复能力。

详细交付与验证记录见 [产品完善清单](./product-improvements)。
