# 更新日志

## 0.0.1-beta2

发布日期：2026-10-22

- 🐛 修复检查更新无法查询预览版的问题，同时识别正式版与预览版并正确比较版本号。
- ✨️ 检测到新版本时展示更新内容与发布入口，检查失败时显示消息提示。
- 🐛 修复全局消息样式缺失，补齐刷新、仓库管理、分组、设置和克隆任务的操作反馈。
- 🎨 补充图标按钮的悬停说明，精简关于页面的顶部提示。

> 测试版，请先备份重要文档；遇到问题请通过 Issues 反馈。

## 0.0.1-beta1

发布日期：2026-10-19

- ✨️ 集中管理本地仓库，支持分组、置顶、组合筛选、分支与工作区操作及批量同步。
- ✨️ 从远程添加或快速克隆仓库，提供总体进度、停止与文件保留选择、目录历史和任务中心。
- ✨️ 业务数据保存到本地 SQLite，支持预览、备份和合并导入导出；偏好独立保存在 JSON。
- 🐛 修复 Windows 克隆路径及进程终止问题，支持失效仓库重新定位并保留管理关系。
- 🎨 统一仓库界面、标签与设置布局，增加开发工具、外观和启动偏好设置。

测试版，请先备份重要仓库管理数据；遇到问题请通过 [Issues](https://github.com/yeyongzhi/RepoDeck/issues) 反馈。
