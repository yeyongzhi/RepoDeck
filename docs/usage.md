# 使用说明

## 添加与查找仓库

「添加仓库」下拉菜单可从本地登记或从远程克隆。固定扫描目录在设置的「仓库」分类维护。搜索可匹配仓库名、路径或分支，结合状态筛选定位项目。置顶项目优先展示，可将选中仓库批量加入分组。

登记只保存项目路径；移除登记不会删除项目代码。失效路径可重新定位并保留分组、置顶和访问关系。

## 远程克隆

输入 HTTPS 或 SSH 地址，例如 `https://github.com/owner/repository.git`，选择已有存放目录并确认项目目录名。目录历史支持点击复用、逐条删除及清空。

「从远程添加」完成后自动登记。顶部加号「快速克隆仓库」默认只下载代码，可用开关选择添加到仓库列表，并选择分组。

进度按接收、解析、检出阶段估算，成功时显示 100%。关闭弹窗后任务继续，可在任务中心查看。点击停止后选择保留或删除本次创建的克隆目录；未完成的代码不会登记。保留文件时重试需使用新目录。

## 日常 Git 操作

点击仓库进入详情，查看总览、分支管理、提交历史和工作区。「更多工具」包含分支对比、Stash、标签和记录。仓库菜单提供 Fetch、审阅提交、快进拉取、推送、打开编辑器或终端等操作。

批量同步先 Fetch；仅当工作区干净、没有本地独有提交且远端领先时自动快进。存在分叉、冲突、缺失 upstream 或 detached HEAD 时按提示处理，不自动改写提交历史。

## 任务与设置

任务中心展示 Git 和克隆记录。退出时有任务可选择等待；停止克隆退出会保留已下载文件。Git 写入任务执行期间不能强制退出。

设置中可选择默认编辑器／终端、启动页、布局和外观。偏好修改自动保存。设置 → 数据支持分别导入导出业务数据及偏好；导入不会替你下载仓库代码。
