## 数据位置与兼容

安装版：

```text
安装目录/
  RepoDeck.exe
  data/repodeck.sqlite
  setting/preferences.json
  setting/window.json
  backup/before-import-时间戳.json
  backup/preferences-before-import.json
```

SQLite 使用 WAL 事务，运行时可能同时出现 `-wal` 和 `-shm` 文件。应用提供的数据导出通过数据库查询生成一致的业务快照，无需手工复制运行中的数据库文件。业务数据包为带版本号的 JSON 交换格式；SQLite 是运行时唯一业务存储。偏好独立保存为 JSON，不包含在业务数据包中。

开发版位置：`%LOCALAPPDATA%/RepoDeck-dev`。数据库已有记录优先，旧 JSON 与浏览器记录只在该分类尚未迁移时导入。读取损坏数据会报告并保留源文件，不能把空默认值写回覆盖。仓库代码、Git 分支与文件状态不复制进数据库。
